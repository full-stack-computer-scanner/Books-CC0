# Books by Keith Charles Johnson — Free and in the Public Domain (CC0)

Welcome! This repository holds books written by **Keith Charles Johnson**, a longtime technical writer, programmer and author. All of them are released under **[CC0 1.0 Universal](LICENSE)**, which puts them in the public domain.

You are free to read, download, print, share, copy, translate, quote, adapt or republish them, for any purpose and without asking permission. Credit is appreciated but not required.

I publish these books so they stay freely available to readers for as long as possible.

---

## How to read a book

Click any title below, then use the **Download** button (the arrow icon at the top right of the preview) to save the PDF to your device.
